# Security Policy

KH PTZ Control is open source (MIT), but please do not disclose suspected security issues in public issues, public pull requests, screenshots, logs or support bundles.

## Reporting

Report security concerns through the maintainer or company contact defined in the customer support agreement or authorised support channel.

If you are working inside this private repository, create a private GitHub issue only when it does not expose secrets, customer data, private network details or exploit instructions that would increase risk.

Use `docs/SECURITY_INCIDENT_RESPONSE.md` for the internal response checklist.

## Do Not Share

Do not post or attach:

- passwords, attempted passwords or password reset data;
- `password.enc`, `password.txt` or `.env` files;
- private keys, signing keys, tokens or licence secrets;
- raw customer backups;
- support bundles that have not been checked for sensitive data;
- customer names, personal data, private IP plans or site-specific network details unless they are explicitly sanitised.

## Supported Scope

Security handling depends on the installed version and the customer support agreement. This file does not promise response times, compliance status or vulnerability bounty terms.

## Deployment Rule

Customer or pilot installations should use approved release candidates or tagged releases only. Do not install customer systems from arbitrary development commits.
